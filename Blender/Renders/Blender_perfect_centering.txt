Female mannequin:
CAMERA CENTERED AT CHARACTER:
Character’s height is Z = 1.74 m, so its vertical center is:
1.74 / 2 = 0.87 m

C = (0, -d, d + 0.87) where d is any positive distance. In this case, d = 8m

Location (0, -8, 8.87)
Rotation (45°, 0°, 0°)
Orthographic Scale 2.5
Render 512×512px

BLENDER MATERIAL COLORS FOR EASY TRACING:
heat_mat	#C74ABF
torso_mat	#4A7FBF
pelvis_mat	#D94A4A
left_arm_mat	#6FBF4A
right_arm_mat	#F2C14E
left_leg_mat	#8A5FBF
right_leg_mat	#3FBFA6
joints_mat	#2B2B33

In the material, we also need to scroll down and change the viewport display color to match the colors above.

FLAT LIGHTING FOR TRACING:
Viewport shading
lighting flat
color -> object -> material
options -> outline black
cavity -> type screen
X-ray and shadows off

TRANSPARENT BACKGROUND:
Go to Render Properties (camera icon).
Scroll to the Film section and check Transparent.
Go to Output Properties (printer icon).
Set File Format to PNG.
Set Color to RGBA (the "A" is the alpha channel)

RENDER RESOLUTION:
Render at 256x256 pixel resolution and use aseprite sprite size to resize to 128x128 then trace over it by hand.
